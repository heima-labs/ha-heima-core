## Scenario review

| Scenario | Result |
|---|---|
| Soil dryness, normal | Off-cycle run every 15 min; fact applied at the next barrier with runtime-assigned `kind="extension"` source. |
| Input unavailable | Snapshot carries `available=False`; the extension decides its output within its contract. |
| Exception or timeout, then recovery | Run discarded, no partial fact; `backing_off`/`faulted`; first success restores `healthy`; never auto-disabled. |
| Extension dead for longer than `max_result_age` | Fact `available=False` at detection, gap recorded; downstream Fusion sees unavailable input. |
| Late result after a generation swap | Discarded. |
| Claim in a core namespace, another extension's namespace, or inside `ext.*` by a core producer | Rejected at staging (Layer 0 §4). |
| Two instances claiming the same key | Rejected (Layer 2 §2.3). |
| Input slot on `presence@casa` or `household.guest_stay` | Rejected at registration. |
| Returned payload sets `kind="sensor"` or an unclaimed fact | Whole run rejected; source fields are runtime-assigned. |
| Watering tries to open a valve | No path: no `ApplyStep`, Actuator call, descriptor or candidate kind. |
| Remove an instance feeding a Fusion, with a pending analyzer proposal | One commit: Fusion consumer breaking, proposal not approvable (CA4-128). |
| Code upgrade at bootstrap | New `implementation_version` changes the fingerprint; dependents classified as a code upgrade. |
| Restart | Runtime state re-derived; one jittered run per instance; no replay. |
| Extension A reads Fusion F, F reads A | Previous-cycle edge; no evaluation cycle. |
| Input changing every 5 s | At most one run per 60 s, single-flight, coalesced. |
| Heavy training competing for the slow path | Admission and starvation protection deferred to CA4-130. |
| Analyzer outputs | Only its bound learners' findings/results; candidate only under its blueprint contract; no `DiagnosticFinding`. |
