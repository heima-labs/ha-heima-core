# CA4-77 — open actionable requests are never silenced

**Status:** specification reviewed (2026-10-13).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision

A silenced family drops only informative phases produced during quiet hours. A phase with answer
buttons whose request is still open is held and delivered when quiet hours end; it retires
undelivered only if its request closes or expires first.

## Scenario review

| Scenario | Result |
|---|---|
| `attention` silenced; recovery confirmation opened at 02:00, open at 07:00 | Delivered at 07:00 with buttons. |
| Same, but the request expired at 05:00 | Retired undelivered; fact remains. |
| `attention` silenced; follow-up warning at 02:00 | Retired undelivered at quiet-hours end. |
| `governance` silenced; consent request at 23:00 | Delivered when quiet hours end. |

Textual review only; no V3 runtime test has run.
