# CA4-03 — recovery baseline granularity and authority

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

The approved recovery rule treats a checkpointed target as a baseline for fresh
current-policy calculation, never a command replay. The developer has additionally
decided that a target from a removed or consent-revoked Reaction must be discarded;
direct administrator/resident targets may remain eligible only under the current
Actuator recovery setting and ordinary admission. Layer 0 §7.4 currently stores one
last-write-wins target per HA entity. That loses independent channels and partial
facets, and it does not retain the producing authority.

Reuse Layer 2's `(actuator_id, controlled_channel)` identity and Layer 5's
`ChannelTarget.targeted_facets`/generation authority checks. Layer 0 owns the copied,
bounded checkpoint projection and coalescing; Layer 5 supplies a trusted authority
anchor at acceptance and validates it on recovery. Layer 2 supplies frozen Actuator
fingerprints/policy at generation cutover. Layer 4's frozen recovery input is CA4-45.
V3 retains clean-start, one action path and current-policy precedence. Review two
channels on one endpoint, successive partial targets, mixed facet origins, a revoked
Reaction, a direct admin target, changed adapter and an invalid combined target.

| ID | Scenario | Required result |
|---|---|---|
| S1 | One endpoint has two registered channels and both receive targets | Two independently keyed snapshots; neither overwrites the other |
| S2 | A channel first targets power and brightness, then only brightness | New brightness and its source replace the old entry; power and its source remain |
| S3 | Reaction A owns power, Reaction B owns brightness; B loses consent | Only B's baseline facet is removed; A retains its value and authority |
| S4 | A removed or edited Reaction is the only source on a channel | No historical fallback command from that channel |
| S5 | Direct admin target survives while another Reaction is revoked | Direct facet remains only under current recovery policy and channel/safety admission |
| S6 | Mixed surviving facets violate the current closed channel target contract | Abstain on that channel; do not guess a subset or erase another channel |
| S7 | Endpoint, adapter semantics or recovery policy changes | Discard affected snapshots before any command or confirmation request |
| S8 | A target changes before the next 60-second checkpoint commit | Recover the preceding completed snapshot or none, never claim an uncommitted value |
| S9 | A merged projection exceeds Layer 1's bound | Accepted command proceeds; touched channel has no recovery baseline and emits a diagnostic |
| S10 | Standalone admin or resident-approved command with no Reaction | `ApplyStep` has no Reaction identity; trusted direct source anchors its target without inventing a Reaction generation |

**Review result:** Layer 0 §7.3–7.4 and acceptance, Layer 2 §2.5/§6/§9, Layer 5
§6/§8, overview and recap agree on channel identity, partial-facet merge,
authority filtering and current-policy admission. CA4-45 remains responsible for
the frozen snapshot transport. No executable V3 runtime test has run.
