# CA4-10 — semantic state-transition trigger input

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

The developer chose a typed previous/current semantic-state pair in one
`DecisionSnapshot`. Layer 0 already seals declared `previous_cycle` state keys;
Layer 4 already returns current semantic claims after its DAG. Layer 5 currently
names `state_transition` but has no same-cycle pair for a Layer-4 state.

The coordinator owns pair construction after Layer-4 completion, using only
the staged exact semantic-state claim and Layer-0's previous-cycle snapshot.
Layer 4 transports it; Layer 5 compares canonical values with the descriptor's
closed transition vocabulary. Missing/unavailable prior or current state, a
restart gap or changed semantic producer semantics cannot be treated as an
edge. Explicit `SemanticEpisode` adapters remain for separately declared
events and are not generated for every state. V3 keeps immutable-cycle
evaluation and the bounded previous-cycle O(1) path. Review transition,
unchanged value, provenance-only change, unavailable state, restart and
equal-time Layer-2 intake versus Layer-4 completion.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Prior semantic `away`, current semantic `present` in completed DAG | Matching transition fires once in this cycle |
| S2 | Current value still `away`, even if confidence/source changes | `not_triggered` |
| S3 | Prior or current state unavailable | `abstained`; no inferred edge |
| S4 | First cycle after process restart or impacted semantic producer | No usable predecessor; `abstained` |
| S5 | Intake contains `on→off→on` within one cycle and prior was `on` | No net state transition; an explicit event is needed to retain the intermediate occurrence |
| S6 | Layer-4 output resolves after Layer-2 barrier | Pair uses completed semantic claim without inserting it into the Layer-2 trigger group |
| S7 | Another fact arrives after the snapshot barrier | Current decision pair is unchanged; next cycle can observe it |

**Review result:** Layer 0 §4.1, Layer 4 §5.1/acceptance, Layer 5 §5.1–5.2/§8,
overview and recap agree on one declared pair and no generic episode mirror.
No executable V3 runtime test has run.
