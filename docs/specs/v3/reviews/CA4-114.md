# CA4-114 — map check in the guided first start

**Status:** specification reviewed (2026-10-16).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 8 §11: steps as ordinary change sets, progress derived from what is
  configured; §9.3 proposal, §9.4 up direction, §9.6 non-blocking map checks, §9.9 editor; §5.1
  address `/heima/house/map`.
- **Gap.** The first start never showed the map, so topology errors surfaced only after devices and
  automations depended on them; §9.11 listed the topic as open.
- **Overlap check.** No new data, command or progress flag. The step reuses the proposal, the map
  checks, the editor and the topology step's form; drawing a staged composition was rejected as
  unnecessary because topology is already applied.
- **Owner.** Layer 8 §11, §9.11, §16.

## Decisions (developer-approved)

1. Step order: rooms → topology → map check → devices → people and notifications → suggested
   automations.
2. The map is the proposal over the active generation, not a preview of unapplied edits.
3. Map checks on top with "Fix" links into the topology form inside the procedure.
4. Three plain-language prompts as help text only; optional layout editor.
5. Never blocking; "Continue" and "Skip" always available.
6. Shown while topology is applied and no device is registered; otherwise passed.

## Scenario review

| Scenario | Result |
|---|---|
| Exterior windows without orientation | "Orientation missing" on top; "Fix" opens the topology form; after apply the check disappears. |
| Two connected rooms drawn apart | "Not adjacent" shown; the administrator drags a box or continues. |
| Administrator continues with open checks | Moves to devices; nothing blocked. |
| Procedure reopened after registering a device | Map step is passed; resumes at the next unconfigured step. |
| Procedure reopened with topology applied and no device | Map step shown again. |

Textual review only; no V3 runtime test has run.
