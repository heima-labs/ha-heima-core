# CA4-63 — weather protection descriptor

**Status:** specification reviewed (2026-10-11).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Gap and V2 reference

V3 guards veto opening or deployment under wind or rain, but no descriptor closes or retracts when
the hazard arrives. V2's `weather_safety` reaction secured covers and openings on a wind or rain
threshold, asked the resident for confirmation, and restored Heima-secured entities when the
hazard cleared; its window classification shared the "window has no connection" gap fixed by CA4-62.

## Decisions (approved)

One direct-only descriptor, one Reaction per hazard; hysteresis trigger whose exit defines hazard
end; explicit staged endpoints restricted to `weather_exposed` Actuators; safe-direction intent `secure_for_weather` with a core-fixed safe target; no required
guard. Endpoint eligibility is exactly `weather_exposed`. (A1) resident holds are respected with a `manual_hold_active` warning; (B1) no automatic
restore; (C1) no runtime confirmation, with a Layer-6 notice of the action.

## Overlap check

Reuses the program evaluator, `safe_direction_intents`, `weather_exposed`/`opening_faces_exterior`,
`numeric.hysteresis_condition.v1`, explicit endpoint persistence (as presence simulation) and the
existing availability occurrence. The only new constructs are the descriptor and the intent
`secure_for_weather`. No hold-preemption priority and no Reaction runtime confirmation were added;
§3.2's "guards are not a right to preempt another writer" stays intact.

## Scenario review

| Scenario | Result |
|---|---|
| Wind hazard, awning extended, window open | Both secured. |
| Window held open by the resident | Not commanded; `manual_hold_active` warning; awning still retracted. |
| Channel already closed | No step. |
| Hazard ends | `natural_completion`; no restore. |
| Restart during hazard | New activation secures from fresh state. |
| Selection with only interior endpoints | Rejected at staging. |
| Interior blind declared `is_external=False` on an exterior window | Not `weather_exposed`; dropped. The window operator on the same opening (undeclared) is exposed and eligible. |

Textual review only; no V3 runtime test has run.
