# CA4-81 — internationalized Layer 6 languages

**Status:** specification reviewed (2026-10-13).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision

`NotificationRecipient.locale` is an HA language code accepted only with an available translation
resource. Templates are translation keys; texts live in per-locale resources with English as the
source; `en` and `it` ship in Initial V3; fallback to `en` for a missing locale or key; dates,
numbers and units are locale- and unit-system-formatted.

## Scenario review

| Scenario | Result |
|---|---|
| Recipient locale `de` with no resource | Rejected at staging. |
| `de` resource added in a later release | Accepted without code change. |
| Key missing from the `it` resource | That text falls back to `en`. |
| Template test finds a literal Italian string in code | Fails. |

Textual review only; no V3 runtime test has run.
