# CA4-78 — retention of past configuration generations

**Status:** specification reviewed (2026-10-13).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision

Every committed `ComposedGenerationManifest` and every layer generation record it references is
retained indefinitely and readable by id (Layer 0 §4.7). Outside fact retention; no pruning job.

## Alternatives rejected

Keeping only the last 100 generations needed a pruning job, an arbitrary limit for restore, and
conflicted with Layer 5's immutable Reaction configuration history. Records are a few KB and are
created only by administrator commits.

## Scenario review

| Scenario | Result |
|---|---|
| 500 commits over years, many fact-retention runs | Every manifest and generation record still readable. |
| Layer 8 reads generation 12 for a diff | Slow-path read; active generation and cycle unaffected. |
| Bootstrap | Loads only the latest manifest, as before. |

Textual review only; no V3 runtime test has run.
