# CA4-110 — runtime error: write-failure end and transition identity

**Status:** specification reviewed (2026-10-16).
**Evidence type:** `textual_contract_and_scenario_review`; the identity collision was reproduced by
Codex with the canonical encoder (transitions 2 and 4 hashed to the same value).
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decision.** CA4-109: error causes, `RuntimeHealthOccurrence`, `system.health`.
- **Gaps.** (1) No rule for which success ends `persistence_write_failing`, nor for setup failures
  and closed-writer refusals. (2) Equal ids for distinct transitions with equal content.
- **Overlap check.** Uses existing write outcomes and owners' retained-work state; outbox key
  semantics (Layer 0 §4.5, Layer 6 §7.6) unchanged. No probe or timer.
- **Owner/dependents.** Layer 0 §10.1, §13; Layer 6 §4.2, §14.

## Decisions (developer-approved)

1. Identity `[run_id, transition_sequence]`; content is not identity.
2. Deliver only `error_opened` and `restored`; `causes_changed` audit only.
3. Outcomes only from actual durable writes; reads, setup without pending writes, empty commits
   and closed-writer refusals do not count.
4. Cause holds while a kind has retained failed work, or nothing has committed since the latest
   failure. Rejected: clearing on any success (flapping), and requiring every failed kind to succeed
   again (false error after a one-shot failure).

## Scenario review

| Scenario | Result |
|---|---|
| Facts fail, stay queued | `error_opened`. |
| Reconnect, nothing written | No change. |
| Empty commit | No change. |
| Metadata commit, facts still failing and queued | No change. |
| Fact retry commits, backlog remains | `restored`. |
| New fact failure | New episode. |
| Generation apply fails (not retained); later checkpoint commits | Opens, then ends at the checkpoint. |
| Facts keep failing while everything else commits | Stays in error. |
| Failed facts discarded by overflow; another write commits | Ends; loss remains a degradation diagnostic. |
| Closed writer refuses repeatedly | Nothing. |
| Causes A, A+B, A, A+B | Four distinct ids; only the opening is delivered. |
