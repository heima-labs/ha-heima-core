# CA4-25 — closed Layer-5 diagnostic outcomes

**Status:** specification reviewed (2026-10-11).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decisions and exact gap

Layer 5 §4.0 declared two evaluation codes and only `late_recovery` for execution audit, while §4.2
deferred governance command results to "the common diagnostic namespace to be completed under
CA4-25" and §7.1/§7.2 required closed outcomes for stale preconditions, unauthorized actors, late
jobs, cancellation, alternate selection and first use without an artifact. The developer approved
a reduced resolution: no new registry; two code sets in the existing `Layer5DiagnosticRegistry`;
descriptor-neutral execution codes with a per-descriptor declared subset; one
`future_work_cancelled` code whose `cause_ref` names the existing cause record.

## Overlap check

| Existing construct | Relation |
|---|---|
| `ProposalTransitionReasonCode` | Records an applied review change; a rejected command changes nothing. Distinct. |
| `ProposalReadinessReasonCode` | Reused as detail of `validation_failed`. |
| `ReactionNormalExitResult`, `ReactionAuthorityTransition`, generation succession | Referenced by `cause_ref`; no duplicate cause vocabulary. |
| `ApplyCallFailureReason` | Attempted calls only; execution-audit codes cover non-call decisions. |
| `ReactionFollowUpOutcome`, `AutomationSuppressionReason` | Resident/availability channels through Layer 6; audit codes never notify. |

## Scenario review

| Scenario | Typed result |
|---|---|
| Promotion with stale expected generation | `rejected` / `stale_precondition`, no mutation. |
| Consent command by a non-resident administrator | `rejected` / `actor_unauthorized`. |
| Retry of an applied command | `idempotent_replay` with the original result. |
| `stage_admin_direct_reaction` for comfort trajectory | `rejected` / `authoring_mode_not_permitted`. |
| Presence-simulation job due after its step window | `late_step_skipped`. |
| Comfort ramp cannot meet return boundary | `late_recovery`. |
| Obsolete callback from a prior activation | `stale_callback_discarded`. |
| Committed return cancels future steps | `future_work_cancelled`, `cause_ref` = normal-exit result. |
| Consent revoked | `future_work_cancelled`, `cause_ref` = authority transition. |
| Held endpoint, alternate bundle admitted / none admissible | `alternate_bundle_selected` / `bundle_skipped_no_admissible_alternative`. |
| Timing role with no adoption yet serves its seed | `fallback_served_without_artifact`, `artifact_ref=None`. |

This is document-level evidence; no V3 runtime test has run.
