# CA4-16 — quantitative unit boundary impact analysis

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision and impact

The developer wants Heima's computational number in a stable canonical unit.
Staging must reject a quantitative binding that has no declared conversion
from its source unit to that canonical unit. Runtime must then reject a
source-unit drift not covered by the staged binding; the UI may convert the
canonical value for display. This is an ingress/calculation issue, not a
display formatting issue.

Layer 2 §3.3 currently treats every HA metadata mismatch as diagnostic-only,
and §4 `NumericInterpretation` passes a finite raw number through unchanged.
The correction must cover numeric and bucket interpretations, because bucket
thresholds also assume a unit. State-level HA unit metadata can be checked
live. An attribute whose entity-level unit metadata does not describe that
attribute needs an explicit source-unit contract at staging; its unit cannot
be inferred from unrelated entity metadata.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Quantitative binding omits unit or required conversion | Staging rejects it before activation |
| S2 | Staged Celsius state later reports `68 °F` | Reading unavailable and diagnostic; no Celsius `68` fact |
| S3 | Fahrenheit source with registered Fahrenheit→Celsius conversion | Canonical Celsius `20` from `68 °F` |
| S4 | Percent source and fraction canonical unit | Declared conversion precedes bucket comparison |
| S5 | Applicable HA unit metadata disappears | Reading unavailable; no guessed unit |
| S6 | Attribute unit metadata is inapplicable | Explicit attribute source-unit contract stages; enclosing entity unit is ignored |
| S7 | Metadata unrelated to numeric scale changes | Diagnostic only, no fabricated unit conversion |

**Review result:** Layer 2 owns staged conversion and runtime unit admission;
Layer 3/5 quantitative consumers demand the canonical unit. A source attribute
that never exposes its own unit cannot reveal an unannounced scale change at
runtime; the explicit developer binding is the authority for that attribute.
No V3 runtime test ran.
