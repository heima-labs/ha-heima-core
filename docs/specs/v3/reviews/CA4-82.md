# CA4-82 — Layer 8 as a read-only consumer of owner changes

**Status:** specification reviewed (2026-10-13).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision

Layer 5 (authority transitions, §6.0 occurrences), Layer 6 (availability-tracker episode changes)
and Layer 0 (recovery-confirmation occurrences, health snapshots, degradation-diagnostic changes)
hand their existing typed changes read-only to Layer 8, outside evaluation. Layer 8 keeps
in-memory projections for automation state, pending items and health, rebuilt at start.

## Overlap check

No new type, record or persistence: the same typed values already go to Layer 6 or diagnostics.
Committed-state observers (Layer 0 §4.8) still feed everything that is a state fact.

## Scenario review

| Scenario | Result |
|---|---|
| Reaction promoted | Automation-state entity becomes `automatic` without polling. |
| Wind blocks an automatic Reaction | Tracker episode -> entity `blocked` with reason; restored -> `automatic`. |
| Proposal created, then accepted | Pending count +1, then -1. |
| Storage outage | Health `degraded` (or `error` if writes fail); back to `ok` after recovery. |
| Restart | Projections rebuilt from current owner state. |
| Slow panel consumer | Owners never wait. |

Textual review only; no V3 runtime test has run.
