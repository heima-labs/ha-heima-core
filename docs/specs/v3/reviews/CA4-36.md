# CA4-36 — environmental formula configuration impact analysis

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact

Layer 2 §5.3 already has a core `RegisteredFormula` compiler and binding
validator for canonical JSON configuration. §2.4 nevertheless says only
`physical_evidence.weighted_evidence` may use it. Layer 3 §4.8.2 requires
one solar formula with staged opening identity/orientation and one humidity
ratio formula with a declared pressure source. Their configuration cannot
stage under the current sentence.

Reuse the formula registry and closed compiled-config types. Solar config
names a registered opening and a stable solar binding, resolving orientation
from Topology at staging. Humidity config selects either a pressure FactRef
among declared inputs or one finite installation reference pressure. No
runtime opening lookup, arbitrary expression, raw HA field or fallback
pressure is added. The solar geometry fact producer itself remains CA4-47.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Same solar inputs, north-facing and south-facing openings | Distinct staged orientation/binding fingerprints and different proxy values |
| S2 | Missing or unsupported orientation, duplicate binding, wrong room or wrong irradiance unit | Staging rejects the invalid formula binding |
| S3 | Geometry mode without radiation facts | Dimensionless proxy only; no W/m² exposure claim |
| S4 | Humidity formula with a bound pressure fact | Uses live canonical pressure; unavailable pressure yields unavailable output |
| S5 | Humidity formula with a finite installation reference pressure | Uses declared constant and requires no pressure fact |
| S6 | Both pressure sources, neither source, invalid pressure or non-finite result | Reject at staging or return unavailable as appropriate; never silently fall back |
| S7 | Topology or formula implementation version changes | Dependent compiled formula and learning generation invalidate under normal fingerprint rules |

**Review result:** Layer 2 §2.4, §5.3 and §9, Layer 3 §4.8.2–4.8.3, overview and
recap now use one registered FormulaStrategy route. CA4-47 still owns the missing
solar-geometry fact producer. No executable V3 runtime test has run.

**Subsequent closure (2026-10-07):** CA4-47 closed the solar-geometry fact producer at
specification level; the references above record its state on 2026-10-05.
