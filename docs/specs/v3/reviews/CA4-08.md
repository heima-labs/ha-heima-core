# CA4-08 — physical-evidence composition review

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision and impact

The developer chose one existing `physical_evidence.weighted_evidence`
fusion with independent corroborating-group quorum for Initial V3. Layer 2's
former fast/confirmed example required intermediate outputs and Fusion inputs
that its own validator forbids. The replacement stages one room-occupancy or
casa-presence output. Immediate sources retain their shortcut; corroborating
sources need at least two independent groups able together to reach the true
threshold. No second intermediate fact, timed confirmation path, or extra
formula type is introduced. A single corroborating group cannot claim a
confirmed path under this recipe.

| ID | Scenario | Required result |
|---|---|---|
| S1 | One available immediate primary is true | Same-cycle true, subject to declared final stability |
| S2 | One corroborating group is true | Does not reach the true threshold |
| S3 | Two independent corroborating groups jointly meet threshold | Same-cycle true candidate, subject to declared final stability |
| S4 | Two readings share a correlation group | At most one group vote; no false quorum |
| S5 | The corroborating groups cannot jointly reach threshold | Only the immediate route exists; the configuration cannot be presented as two-route |
| S6 | A false result is requested | Required-for-false groups, threshold and final false stability still apply |

**Review result:** the recipe is expressible by the existing validator and one
registered formula. The general formula still permits a deliberately positive
true dwell in other configurations; this Initial-V3 two-route recipe does not
depend on a separate timed confirmation mechanism.
