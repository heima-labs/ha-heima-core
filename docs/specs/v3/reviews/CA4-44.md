# CA4-44 — common Reaction administration impact analysis

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact

Layer 5 §4.2 already defines one immutable configuration and authority
lifecycle for every `ConfiguredReaction`. §7.1.1 exposes callable commands
only for comfort trajectory, leaving the other Initial-V3 descriptors unable
to exercise that lifecycle through Layer 8. The developer previously chose a
common command surface; the comfort prerequisite staging command is the sole
descriptor-specific preparation step.

The shared operations need exact reaction/configuration generation and
current authority preconditions, authenticated actor role, atomic mutation,
idempotent retry, and common validation. They must not copy descriptor
parameters into authority transitions or make a command itself issue an
`ApplyStep`. The panel can render descriptor-specific forms while sending
the same typed commands.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Admin stages complete presence simulation or routine configuration | Common direct command creates `notification_only` generation |
| S2 | Admin accepts an environmental or comfort proposal | Common review command creates learner-origin `notification_only` reaction |
| S3 | Admin promotes without required resident consent | Shared authority transition; `authorized_awaiting_household_consent`, no command |
| S4 | Authorized resident grants/revokes consent | Exact-generation authority update; fresh evaluation or immediate stop |
| S5 | Admin disables any descriptor | Future jobs cancelled; audit and configuration preserved |
| S6 | Retry, stale generation, stale authority version or changed request id | Idempotent prior result or atomic rejection; no duplicate transition |
| S7 | Comfort prerequisite staging | Descriptor-specific preparation only; common promotion/consent commands still apply |

**Review result:** §4.2 owns one callable governance surface for all six
descriptors. §7.1.1 now references it rather than defining duplicate
comfort-only aliases. Exact diagnostic result codes remain tracked by CA4-25;
this review closes command ownership and lifecycle, not that namespace.
