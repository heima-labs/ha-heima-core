# CA4-133 — shadow requirement of the room-return survival model

**Status:** specification reviewed (2026-10-21).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 3 §4.7 closed `shadow_requirement` values as the only gate to an
  operational state; §9 staging rejects a missing value; CA4-13 (`RoomOccupancySurvivalModel`,
  `return_delay` action-serving timing artifact); CA4-14 and §4.9 artifact adoption through
  `reaction.artifact_adoption` proposals; Layer 5 §4.2 staged seed delay as fallback.
- **Gap.** No declared value for the model (audit F-L3a-01, F-L3b-03); the `ShadowPreviewBinding`
  rule covered every proposal-producing type although only `reaction.descriptor` bindings exist
  (F-L3b-04).
- **Overlap check.** Reuses the closed values, the existing censoring-aware validation measures as
  shadow gate, the adoption path and the seed fallback; no new type or value.
- **Owners.** Layer 3 §4.4.1, §4.7, §9. Layer 5 unchanged (it already consumes only adopted or seed
  timing).

## Decisions (developer-approved 2026-10-21)

1. `stay_duration`: `not_applicable`; `return_delay`: `required_before_proposal`.
2. `proposal_eligible` covers `reaction.artifact_adoption` candidates.
3. `ShadowPreviewBinding` applies only to `reaction.descriptor` producers.

## Scenario review

| Scenario | Result |
|---|---|
| Validated `return_delay` artifact, shadow not yet passed | No adoption candidate; Reaction serves its seed delay. |
| Shadow on live anchors, horizons maturing or censored | Scored with calibration, IPCW concordance and baseline comparison; no action. |
| Shadow gate passes | Artifact `proposal_eligible`; one `reaction.artifact_adoption` candidate for review. |
| Shadow gate fails or drifts | Artifact unadoptable; seed delay continues. |
| `stay_duration` artifact | Diagnostic only; no shadow state. |
| Staging of the type | Each profile declares one value; no `ShadowPreviewBinding` required for the adoption producer. |
