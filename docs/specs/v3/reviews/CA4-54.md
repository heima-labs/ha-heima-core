# CA4-54 — one time representation across V3 contracts

**Status:** specification reviewed (2026-10-07).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decision and impact

The developer reconfirmed the original V3 rule: one representation for time
everywhere. The former A/B wording in the backlog was an erroneous reopening
of that decision. Every declared instant is `EvidenceInstant` in Layer 1's
single UTC microsecond `+00:00` form; every positive elapsed duration is
Layer 0's `Window`, with canonical seconds. A zero point horizon means the
anchor itself and is represented by `None`, not a second duration type.
Civil weekday/hour/minute components are calendar coordinates, not elapsed
durations. Parsers and arithmetic may temporarily use implementation-native
datetime/timedelta objects, but no V3 contract stores, publishes, fingerprints
or transfers those objects or an alternate `Z`/integer-millisecond time form.

**Exact gap:** Layer 1 `HouseFact.when`, Layer 0 jobs/calendar snapshots, and
Layer 3 sample/result/publication fields used `datetime` or `timedelta`
beside `EvidenceInstant` and `Window`; Layer 3 additionally prescribed `Z`
instants and integer-millisecond duration fields for artifact JSON. The same
instant/duration could therefore acquire two canonical bytes and unequal
fingerprints across layer boundaries.

**Existing constructs and owners:** Layer 1 §4 defines `EvidenceInstant`;
Layer 0 §3 defines `Window` and timing validation. Their formats own the
common wire rule. Layer 3 §§4.1–4.4/§9 owns learning bindings, result envelopes
and artifact codec; Layers 0/1/5 own job, fact and Reaction fields that cross
the boundary. The overview, recap, backlog, acceptance and contract registry
follow this bounded correction. The V2-to-V3 constraint is one typed substrate
across sensor, model, Reaction and Actuator paths rather than a conversion
convention invented per feature.

## Scenario review

| Scenario | Required contract result |
|---|---|
| The same observation appears in a fact, model artifact and Reaction audit | All three use exactly the same `EvidenceInstant` bytes. |
| A model horizon and a Reaction window both mean 90 seconds | Both use the same `Window(seconds=90)` semantics and canonical `{"seconds":90}` JSON; no `90000` millisecond alias. |
| A point outcome is evaluated at its anchor | `horizon=None` means zero elapsed time; `Window` remains strictly positive. |
| A scheduled job crosses a DST boundary | Civil recurrence components stay local; the resulting due instant is normalized once to `EvidenceInstant` UTC. |
| A historical gap or unavailable sensor yields no usable event | Its temporal boundary uses `EvidenceInstant`; availability/censoring semantics are unchanged. |
| A model rounds its selected wait to milliseconds | That is calculation precision; any declared/stored duration is still a `Window`. |
| Two fused occupancy levels contribute 120 and 60 seconds of false dwell | The published `StabilityPathSummary.to_false_delay` is `Window(seconds=180)`; the zero true path is `None`. |
| A resident correction is simultaneous with its full-target observation | The anchor fields identify the attribution; `attribution_elapsed=None` denotes zero elapsed time without creating a zero-valued `Window`. |
| A thermal model publishes a recovery duration | The parameter uses `Window` fields, and Layer 5 consumes those same fields without converting to an independent seconds contract. |
| A noncanonical `Z` instant or integer millisecond duration reaches an artifact boundary | Validation rejects it instead of silently converting only in Layer 3. |

The owner contracts and dependent references were checked for `datetime`/`timedelta`
dataclass fields, scalar-seconds duration fields, old `LearnedWindow` names and alternate
artifact encodings. Remaining millisecond arithmetic belongs only to the internal selector
formula. These are specification scenarios. No executable V3 test has run.
