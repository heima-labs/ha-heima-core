# CA4-07 — physical-evidence confidence review

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review` (including numeric cases).
**Runtime test:** `not_run_v3_not_implemented`.

## Impact

Layer 2 §5.3 owns the physical-evidence vote and calls Layer 1's shared
`categorical_confidence(support, total)` function. The current denominator
is ambiguous: confidence-weighted vote totals make a sole low-confidence
primary look fully reliable. The existing immediate-primary shortcut and
group-correlation rule must stay intact. The correction must apply to both
room occupancy and casa presence; no source kind gets a special formula.

The reusable denominator is the sum of configured directional weights of
retained, non-conflicted group votes, before multiplying by each selected
fact's confidence. The support remains the winning-direction weighted sum.
Thus reliability and disagreement both reduce the reported confidence. An
unavailable or conflicted group has no denominator contribution; same-group
siblings contribute at most once. The positive true weight ensures an
immediate primary always has a positive denominator, even at confidence zero.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Sole immediate primary, true weight 2, confidence 0.2 | `True`, `support=0.4`, `total=2`, confidence 0.2 |
| S2 | Same primary at confidence zero | `True`, `support=0`, `total=2`, confidence zero |
| S3 | S1 plus independent false vote, false weight 1, confidence 1 | Immediate `True`, `support=0.4`, `total=3`, confidence `0.4/3` |
| S4 | Two same-direction correlated inputs | One selected group vote and one configured weight enter the ratio |
| S5 | Contradictory observations in one group | No vote or denominator contribution from that group |
| S6 | No qualifying true or false result | `available=False`; categorical confidence is not called |

**Review result:** Layer 2 §5.3 and §9 now use one denominator for both
physical occupancy and presence. The shared Layer-1 confidence function
remains unchanged. This is a specification review only.
