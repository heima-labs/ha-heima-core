# CA4-154 — mapping output set and fact value contract

**Status:** specification reviewed (2026-10-24).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** CA4-153 `FactValueContract`; Layer 2 §3.2 total/partial mapping via
  `NO_DEFAULT`; the 2026-09-08 decision admitting `default=None` as a real value.
- **Contradiction.** A `None`, numeric, object or mixed mapping output has no `FactValueContract`;
  the 2026-09-08 allowance is reopened for that concrete case only.
- **Overlap check.** No new construct; `NO_DEFAULT` already expresses "no interpretable value";
  numeric quantities already use `NumericInterpretation`/`BucketInterpretation`.
- **Owners.** Layer 2 §2.3, §3.2, §4 (`MappingInterpretation`), §9.
- **Responsiveness.** Staging only.

## Decision (developer-approved 2026-10-24)

Option A: mapping outputs restricted to booleans or to strings; anything else rejected at staging.

## Scenario review

| Scenario | Result |
|---|---|
| `{"on": True, "charging": True}`, `default=False` | `boolean`. |
| `{"home": True}`, `NO_DEFAULT` | `boolean`; unmapped state `available=False`. |
| `{"playing": "playing", "paused": "paused"}`, `default="idle"` | `categorical(idle, paused, playing)`. |
| `default=None` | Rejected at staging. |
| `{"low": 1, "high": 2}` | Rejected; use a numeric or bucket interpretation. |
| `{"on": True, "eco": "eco"}` | Rejected (mixed kinds). |

Textual review only; no V3 runtime test has run.
