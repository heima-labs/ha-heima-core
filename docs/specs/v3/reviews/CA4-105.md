# CA4-105 — house-map layout residues

**Status:** specification reviewed (2026-10-15).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decision.** CA4-103 layout rule; CA4-104 cross-floor connections.
- **Gap.** Unreachable rooms were placed touching the others (false contiguity); several exterior
  strips on one side could overlap; the rationale and postponed refinements were not recorded.
- **Overlap check.** Groups reuse the existing passable-opening relation; `unconnected_ok` is
  Layer-8 presentation data beside the existing placements, like the other map checks. No new
  Layer 0–5 contract.
- **Owner.** Layer 8 §9.2, §9.3, §9.6, §9.11, §16.

## Decisions (developer-approved)

1. Connection groups per floor; separate groups move as a block with one empty cell between, on
   their preferred side, below by default.
2. "Not connected" map check, dismissible per room.
3. Exterior strips on one side ordered along it, stacked outward on overlap; a corner balcony is
   one strip (accepted approximation, to refine later).
4. Rationale and deferred refinements recorded in Layer 8 §9.11; the map topics still open are
   listed there for the next discussion.

## Scenario review

| Scenario | Result |
|---|---|
| Garage on the apartment floor, only a door to outside and an east window | Own group, placed east with one empty cell; "Not connected"; dismissible. |
| Two-room annex joined to each other but not to the main block | One group of two, laid out together and moved as a block. |
| Group containing a pinned room | Laid out around its pinned rooms; never moved as a block. |
| Terrace and garden both south | Ordered along the bottom; on overlap the second moves one band further out. |
| Balcony with door-windows on south and east rooms, mostly south | One strip at the bottom. |
| Room with a staircase `passage` only (no same-floor connection) | Own group on its floor; not "Not connected", because it connects to another floor. |

Textual review only; no V3 runtime test has run.
