# CA4-22 — signal admission and expiry wakeup

**Status:** specification reviewed (2026-10-11).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decisions and exact gap

Layer 4 §6 admitted a signal only when `emitted_at < snapshot.when < expires_at`, which rejected a
signal stamped at the receiving cycle's own instant, and the order of Layer-3 emission relative to
the cycle barrier was undefined. No owner woke evaluation when an admitted signal expired, so an
assisted conclusion could stay visible until unrelated input arrived. The developer approved:
(1) in-cycle emission after the Layer-2 barrier and before Layer 4, `emitted_at` equal to the cycle
instant, admission `emitted_at <= snapshot.when < expires_at`; (2) one replaceable `elapsed`
Layer-0 `AtJob` per `(contract_id, subject)` at `expires_at`, whose due requests a fresh evaluation.

## Reuse and owners

Layer 3 §6.3 owns emission timing and the expiry job; Layer 4 §5.1/§6 owns snapshot inclusion and
admission. The job is the ordinary Layer-0 `AtJob` (§3.1 replacement and cancellation semantics,
§3.5 cycle instant); no signal store, signal history or new scheduler is introduced. The
`elapsed` basis follows the TTL meaning of `expires_at`; a wall-clock correction neither shortens
nor repeats the wakeup, and the due cycle re-checks freshness from inputs.

## Scenario review

| Scenario | Required result |
|---|---|
| Signal emitted at cycle instant `t` | Admitted in the same snapshot (`emitted_at == when`). |
| `expires_at == t` | Absent; exclusive upper bound. |
| No input until expiry | Expiry job cycle at `expires_at`; re-emitted if still qualifying, otherwise assisted conclusion retracted. |
| Newer emission before expiry | Job replaced with the new `expires_at`. |
| Cycle with no emission for that pair | Job cancelled; conclusion already absent. |
| Contract/artifact removed at a generation swap | Job cancelled at the swap. |
| Restart before expiry | No signal or callback carried forward; first cycle emits from fresh inputs. |
| Same-cycle Layer-4 output | Never read by the emitter (no feedback). |

This is document-level evidence; no V3 runtime test has run.
