# CA4-98 — backward clock correction without a frozen cycle

**Status:** specification reviewed (2026-10-14).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Approved decision.** CA4-20: threshold strictly greater than 1 s in either direction; cycle
  instant `max(wall, previous + 1 µs)`; `wall_clock` jobs re-armed, `elapsed` countdowns
  untouched; a forward jump or a backward jump over 1 s opens a process-wide
  `clock_discontinuity` gap (20c/A); a backward jump emits `clock_regression`.
- **Gap.** The backward gap was bounded by "the first frozen cycle instant", which does not exist
  when the corrected wall clock stays ahead of the cycle floor (wall 12:00:00 → 12:00:58 over
  60 monotonic seconds). Detection by the 60-second check and the sub-second diagnostic
  condition were unstated.
- **Reused construct.** The forward-jump bounds (last cycle instant before → first cycle instant
  after), which cover the same uncertainty: a duration measured across the correction is wrong
  by its size.
- **Owner/dependents.** Layer 0 §3.5 (owner), §3.1, §4.4, §10, §13.

## Clarification

1. A backward discontinuity always emits `clock_regression`, re-arms `wall_clock` jobs and opens a
   gap. Wall still ahead of the floor: forward-jump bounds. Wall behind the floor: unchanged
   frozen-floor bounds.
2. Detection by the periodic check acts at detection (re-arm, diagnostic, gap opened), bounds the
   gap on the adjacent cycle instants, and is not detected again by the next cycle, which compares
   against that check.
3. A correction of at most 1 s opens no gap; `clock_regression` is emitted only when it puts the
   wall clock behind the floor (the case the cycle-instant rule absorbs).

No product choice: each point follows from the approved rules. Bootstrap/downtime separation,
elapsed countdowns and §4.4's conservative acknowledgement are unchanged.

## Scenario review

| Scenario | Result |
|---|---|
| 12:00:00/0 s → 12:00:58/60 s at a cycle start | `clock_regression`, re-arm, gap 12:00:00 → 12:00:58; no frozen instant. |
| Same correction found by the 60-second check | Re-arm and diagnostic at the check; gap from the last cycle instant to the next cycle instant; the next cycle detects nothing new. |
| −2 s with the wall clock behind the floor | Frozen-floor bounds as before. |
| −0.5 s, wall still ahead | Nothing. |
| −0.5 s, wall behind the floor | `clock_regression` only; no gap. |
| Read spanning a gap whose end is unacknowledged | Incomplete (§4.4). |
| Armed 30-minute `elapsed` hold during the correction | Expires after 30 monotonic minutes. |
