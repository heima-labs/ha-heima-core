## Checked and unchanged

Layer 3's `CanonicalJsonObject`, `BucketValue` and artifact codec and Layer 0's `Window` are
stricter than the domain and remain valid. Layer 2's numeric parser normalizing an HA integer to a
finite `float` is the declared `NumericInterpretation` semantics, not a payload coercion. Static
interpretation values already pass `validate_house_fact_value`. The serialization examples contain
no out-of-domain number.

| A formula configuration contains a large integer | Governed only by that formula's configuration contract. |
