## Scenario review

| Scenario | Result |
|---|---|
| Orderly shutdown, matching clean marker, restart | Declared keys pre-hydrated; a key impacted by the new generation still has no predecessor. |
| Crash restart | Snapshot empty; every `previous_cycle` reference unavailable for the first cycle. |
| Resident switches a channel with no confirmed Reaction target | `actuator.manual_control` emitted, no hold. |
| Guest overrides a confirmed Reaction target | Qualifies under §6.2; hold with `manual_actor="guest"`. |
| Recovery snapshot of a colour light, three facets | Envelope with facet values as canonical JSON text; within 8 KiB; accepted. |
| Prepared follow-up record | Envelope; only `intent` checked as `PersistedProjection`. |
| Oversized recovery target | Command proceeds, no baseline, diagnostic. |
| Actuator rebound to a new `entity_id` | Fingerprint mismatch at cutover; snapshots discarded. |
| Actuator or channel removed | No candidate entry; snapshots discarded. |
| Resolver during `startup_recovery` | No recovery input; Layer 5 alone acts conservatively from `FrozenRecoveryView`. |
| Live signal with a 30-minute `event_count` feature | Event requirement staged; slice read at the barrier; a later append invisible. |
| Same feature after a buffer gap | Slice `None`; signal absent, not low-confidence. |
| Emitter tries to read a Layer-5 requirement id | Rejected. |
| Signal emitted in cycle N | Carries cycle N's `correlation_id`; Layer 4 accepts it as part of the closed payload. |
| Quiet healthy interval | Baseline records engine CPU usage as `C_engine_baseline`; `C_slow` computable. |
| Platform without cgroup | Process CPU time still available from the standard library; capacity `C` may be absent and the planner stays conservative. |
| `require_confirmation` channel, target differs | Proposal handed over; request opened once; identical later cycles reuse it. |
| Unrelated fact changes on another channel | Fingerprint unchanged; request stays open. |
| Channel becomes unreadable | `inadmissible`; request `invalidated`. |
| Observation already matches target | `already_satisfied`; request `cancelled`; no command. |
| Resident approves, nothing changed | Same fingerprint; CAS `approved`; one `ApplyStep` with `kind="user_response"`; anchors preserved; no hold. |
| Approval after the target changed | Fingerprint differs; terminal state recorded; no command. |
| Revoked Reaction consent before approval | Facet filtered; `inadmissible` or a changed proposal; old request closed. |
