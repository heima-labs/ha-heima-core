# CA4-139 — generation and dependency-index rules

**Status:** specification reviewed (2026-10-21).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 0 §4.7 composed generation, staging-only dependency index and
  breaking/semantic_only classification; authority and adoption transitions outside that path
  (Layer 0 §4.7, Layer 3 §4.9); Layer 3 §4.1.2 analysis-definition and serving-generation
  fingerprints and learning definitions as index consumers; Layer 5 §4.2 exact
  `ReactionTimingModelBinding` pin and `configuration_invalid`; Layer 5 §4.2 binding enablement
  through `BindingEnablementChange`.
- **Gap.** Audit group G3: F-X3-01, F-X5-03, F-L3a-03, F-X7-01.
- **Overlap check.** The index gains one producer kind and one consumer kind, without a new
  mechanism; learning definitions were already index consumers. The binding rule reuses the
  existing `user_visible` and `enabled` fields and the existing enablement hand-off.
- **Owners.** Layer 0 §4.7 and §13; Layer 3 §4.1.2, §4.7; Layer 5 §3.2 and §8; Layer 6 §9.2.
- **Responsiveness.** All four corrections act at staging or in wording; the hot path is unchanged.
  An invalidated Reaction leaves evaluation through the existing `configuration_invalid` mode and
  O(1) dispatch fence.

## Decisions (developer-approved 2026-10-21)

1. F-X3-01: option A, learning definitions as producers and timing-model bindings as consumers in
   the Layer-0 index.
2. Mechanical corrections for F-X5-03, F-L3a-03, F-X7-01.

| Scenario | Result |
|---|---|
| Change set removes a learning definition used by a timing-model binding | Reaction listed `breaking`; after commit `configuration_invalid`, needs a successor and fresh promotion. |

| Learner scheduling-only parameter changed | Fingerprint unchanged; binding `unaffected`; no confirmation for it. |

| Change set removes a Sensor bound by a learner | Learner binding fails against the candidate; listed `breaking`. |

| Resumable Reaction staged with `user_visible=False` binding | Rejected by Layer 5 and Layer 6 staging. |

| Disablement | Binding disabled by the same hand-off. |
