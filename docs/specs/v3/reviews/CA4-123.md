# CA4-123 — learning only the household's behavior

**Status:** specification reviewed (2026-10-19).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Approved people model invariant 4, §5.1, §5.2, Q5, D8 (D7 applied in
  CA4-120); CA4-119 resident evidence classes; CA4-121 `household.guest_stay`; CA4-122
  `occupied_without_residents`; Layer 3 §4.2 common sample builder, censoring and coverage rules,
  §4.4.2–§4.4.4 learners, §6 egress.
- **Gap.** No learner excluded periods with a guest, house sitter or cleaner inside, and nothing
  distinguished behavior learning from physical learning.
- **Overlap check.** One rule in the common builder and episode assemblers, using the existing
  censoring and coverage machinery; one new censoring reason; classification derived from the
  existing `SampleBinding` slots. No per-learner exception.
- **Owners.** Layer 3 §4.2, §4.4.4, §9; overview.

## Decisions (developer-approved 2026-10-19)

1. Behavior vs physical is derived per instance from features, outcomes and episode members reading
   a core-owned list of person-related facts; anchors and cohort boundaries do not count.
2. Behavior samples are `censored_by_household_context` when they intersect
   `occupied_without_residents` `True` or unavailable, or, during an active guest stay, touch a guest
   room (default guest rooms while the stay is unavailable).
3. Censored samples are never negatives; physical instances are unchanged.
4. Behavior instances' live egress abstains in the same periods; no novelty finding for a stay.

## Scenario review

| Scenario | Result |
|---|---|
| House sitter switches living-room lights with residents away | Routine episodes censored, never `no_resident_control`. |
| Three-day stay in room 2, residents home | Room 2 samples censored; living room keeps learning. |
| Novelty instance with an occupancy feature | Behavior: no training on, and no finding during, the stay. |
| Novelty instance with HVAC and temperature features only | Physical: unchanged. |
| Thermal model during the sitter's visit | Physical; the visit is not an empty-house cohort (CA4-120). |
| A resident's tracker unavailable | Claim unavailable; behavior samples censored. |
| Occupancy-assist signal for the guest room during the stay | Abstains with a diagnostic. |
| Guest-stay fact unavailable | Default guest rooms censored. |

Textual review only; no V3 runtime test has run.
