# CA4-159 — exact event producer inventory

**Status:** specification reviewed (2026-10-26).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 0 §4 type-level `FactTypeClaim`; §4.7 dependency index of producer
  claims `(fact_type, Location)` for state; Layer 3 §4.2 event anchors/outcomes and the rule that an
  absent occurrence in a complete window is valid; Layer 4 episodes; Layer 7 extension event claims;
  Layer 5/6 event facts at Reaction subjects.
- **Gap.** No exact `(fact_type, Location, owner)` inventory for events.
- **Overlap check.** Extends the existing claim pass and index; declarations are derived from each
  owner's staged configuration, mirroring state-producer claims; no runtime query surface.
- **Owners.** Layer 0 §4, §4.7, §13; Layer 3 §4.2; Layer 4 §4.1; Layer 7 §6.
- **Responsiveness.** Staging plus one O(1) membership check per event append.

## Decision (developer-approved 2026-10-26)

Option A: Layer 0 owns the composed exact inventory; producing layers declare.
