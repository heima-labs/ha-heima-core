## Decisions (developer-approved 2026-10-19)

1. Advice-only Layer-5 descriptor, named `safety.posture_check` so its advisories are `safety`
   (immediate, quiet hours included); residents only; no consent required; no command.
2. Core fact types `security.alarm_mode`, `security.lock`, `opening.open` with closed vocabularies.
3. Checks a–d (alarm armed while occupied, entry unlocked while empty, exterior opening open while
   empty in rain, alarm disarmed while empty), each depending only on casa occupancy and observed
   state.
4. Delays: defaults 5 / 10 / 0 / 15 min, administrator-tunable within 1–30, 2–120, 0–30, 5–120 min.
5. `check_alarm` may have a casa subject with no endpoint; `jammed` counts as not locked;
   `arming`/`pending` never trigger check a.

## Scenario review
