## Findings

### F-X6-01 — Learned-timing binding must match a `FutureStateFractionOutcome`, but the routine's only timing path is a survival model that Layer 5 forbids coercing to one

- **Category / severity:** C / P2
- **Locations:** `docs/specs/v3/layer3_learning_spec.md:3765-3771` — "Where a descriptor version
  permits learned timing, its closed root schema may carry the canonical data projection of the
  stable `ReactionTimingModelBinding` that Layer 5 §4.2 validates. That binding names the learning
  definition, sample/result contracts, exact typed state, qualifying values and authorized window;
  the condition state and qualifying values must exactly match the `FutureStateFractionOutcome`
  source and set."; `docs/specs/v3/layer3_learning_spec.md:1045-1047` — "`return_delay` may also
  publish a validated, reviewable action-serving artifact for the exact registered Layer-5
  `routine.actuation_bundle` vacancy-delay path."; `docs/specs/v3/layer5_action_reactions_spec.md:1574-1576`
  — "The Reaction's continuation condition and the learner's declared typed source/qualifying set
  must be identical; the survival path binds its `return_delay` profile and is never coerced into a
  state-fraction outcome."; `docs/specs/v3/layer5_action_reactions_spec.md:3580-3584` — "This timing
  role is supplemental to the deterministic admin-direct bundle or the ordinary
  `ActuationRoutinePatternModel-v1` bundle candidate; it never learns or substitutes the bundle
  target. The optional binding is exactly `RoomOccupancySurvivalModel.return_delay` with §6.0's
  selector"; `docs/specs/v3/layer5_action_reactions_spec.md:4570-4573` — "a binding to
  `stay_duration`, a scalar fraction, a different result schema or an absent maximum curve horizon
  rejects staging."
- **Owner:** Layer 3 §6.4 — Layer 5 §4.2/§6.0 own the binding contract and register two timing
  selectors (state-fraction and room-return survival); Layer 3's restatement names only one.
- **Defect:** The only Initial-V3 descriptor timing path reachable from a learned candidate is the
  `routine.actuation_bundle` `room_vacancy_return_delay` path, whose binding Layer 5 requires to be
  exactly `RoomOccupancySurvivalModel.return_delay` (a `TimeToEventOutcome` / `SurvivalResult`)
  and rejects if it is a scalar fraction. A routine `ReactionDescriptorCandidate` carrying that
  binding in `descriptor_parameters` cannot satisfy Layer 3 §6.4's requirement that its condition
  and qualifying values "exactly match the `FutureStateFractionOutcome` source and set", since no
  such outcome exists in the binding; conversely, a binding satisfying Layer 3 is rejected by
  Layer 5 staging for this path. Layer 3's candidate-shape preflight and Layer 5's staging thus
  disagree on which bindings are legal.
- **Proposed direction:** Restate in Layer 3 §6.4 that the binding must match the outcome
  contract of its registered timing path (state-fraction source/set, or the room-return survival
  anchor/target and `("absent",)` continuation), deferring to Layer 5 §4.2/§6.0.
- **Confidence:** high
- **Verification:** pending
