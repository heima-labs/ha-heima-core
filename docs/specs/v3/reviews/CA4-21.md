# CA4-21 — historical aggregates and tier-scoped requiredness

**Status:** specification reviewed (2026-10-11).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decisions and exact gap

Layer 3 §4.2 named `mean`, `true_duration`, `minimum`, `maximum`, `rate`, `event_count` and
sequences without defining weighting, interpolation, window boundaries or gap handling on
write-on-change history, and discarded the whole sample whenever any required feature was
missing, which blocked the coarser-tier fallback promised by §4.3. The developer approved:
(a) zero-order-hold state aggregates over `[T - window, T]` with a time-weighted mean, events and
sequences over `(T - window, T]`, canonical equal-time ordering, most-recent truncation and
removal of the redundant `rate`; (b) requiredness scoped to the consumers that read a feature.

## Reuse and owners

Layer 3 §4.2 owns the "Causal window semantics" and "Requiredness scope" rules; §4.3 tier
selection is unchanged and already tier-local at serving. Layer 0 §4.4 coverage and the
`FutureStateFractionOutcome` reconstruction are reused; no new type or field is introduced.

## Scenario review

| Scenario | Required result |
|---|---|
| 30 min window: 20 C for 25 min, 26 C for 5 min | `mean` 21.0 C, `maximum` 26 C. |
| Record exactly at `T` | Zero weight in `mean`/`true_duration`; included in `minimum`/`maximum`. |
| Event at `T - window` / at `T` | Not counted / counted. |
| Source unavailable for 1 min inside the window | Feature missing; no partial aggregate. |
| Two sequence items at the same `when` | Canonical serialization order; never `AppendOrder`. |
| Required `darkness` missing (rich tier only) | Excluded from rich tier; counted in coarse tier; serving falls back with `missing_dimension`. |
| Required feature of every tier missing, or outcome missing | Whole sample discarded. |

This is document-level evidence; no V3 runtime test has run.
