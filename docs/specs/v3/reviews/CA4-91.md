# CA4-91 — one presentation-name rule

**Status:** specification reviewed (2026-10-14).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Decision (approved, S6 of the CA6 reread)

Layer 2 §2.7 states one rule for `Room`, `Zone`, `Opening`, `Sensor`, `Actuator` and Reaction:

- `display_name` everywhere (required for `Zone`), excluded from semantic fingerprints; `Sensor`
  gains the field.
- Fallback live from HA (Room area name, Sensor/Actuator entity name) or composed through
  translation keys (Opening, Reaction).
- Explicit names at most 64 Unicode characters after NFC (S6 (i)); renderers still truncate live
  names.
- Effective names unique per kind within a scope: global for Room, Zone, Reaction; same
  `Location` for Sensor and Actuator; owning room for Opening. Comparison trims, NFC-normalizes
  and case-folds; composed names are compared in every shipped locale. A composed collision needs
  an explicit name. Live HA names are not checked.
- Layer 6 templates use the Reaction name.

The CA4-84 review's statement that Sensors had display names was inaccurate; this change makes it
true. The Layer 2 §2.1 non-goal saying Layer 2 does not own the Room inventory, stale since CA4-83,
was corrected.

## Alternatives rejected

- Minimal fix (Actuator fallback and Reaction name in templates only): keeps per-object rules and
  the duplicate composed opening names.
- Automatic ordinal suffixes for composed collisions: a name would change when a sibling is
  removed, and it would be a second rule beside the Reaction one.

## Overlap check

Generalizes the CA4-85 normalization and "composed collision needs an explicit name" rule instead
of adding a parallel one. One new field, `Sensor.display_name`, needed because Sensors appear in
explanations, the map and the Devices section. No new type.

## Scenario review

| Scenario | Result |
|---|---|
| Two unnamed south windows in one living room | Second rejected at edit validation; naming one applies. |
| Same composed opening name in two rooms | Valid. |
| Two Zones "Piano terra" and "piano terra " | Rejected as duplicates. |

| Sensor without a name | Shows the HA entity's current name; HA rename needs no commit. |
