# CA4-09 — historical channel and target evidence

**Status:** specification reviewed (2026-10-07).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decision and gap

The developer approved a change-only historical state for each registered
Actuator channel, linked by edge id to the unchanged three-field
`actuator.resident_control` event. Layer 5 must publish durable admitted
target-decision, first complete-target observation and episode-close phases
for zero-correction denominators and supersession. Existing
`actuator.correction` remains the resident-count evidence. A dumb wall switch
making a bulb unavailable is an observation break, not a resident control or
correction; on return the first reading is a new epoch and normal policy
resumes without reconstructing a hold.

The normative gap is not live matching: Layer 0 §5.1.1 already normalizes
facets and edge origin, and Layer 5 §6.0.1 already matches complete targets.
The gap is durable, bounded history and join semantics for Layer 3
§§4.4.2–4.4.3. Layer 5 §6.1 also simultaneously restricts attribution input
to resident events and permits external/unknown diagnostics.

## Reused constructs and owners

Layer 0 §4 already supplies state write-on-change, event append, exclusive
claims, per-stream retention and typed observation coverage. Layer 0 §5.1.1
supplies the verified edge id/origin. Layer 2 §6.1 supplies frozen finite
facet grammar, observable-state contract and bounds. Layer 5 §6/§6.0.1
supplies `ApplyStep`, target matcher, already-satisfied and pending outcomes.
Layer 3 §§4.4.2–4.4.3 owns only the historical join and sample rules.
Layer 1's depth-two/8 KiB value rule and canonical facet text codec bound
all stored values. The exact three-field resident event and Layer-5
correction event ownership remain unchanged (CA4-46).

V2-to-V3 constraints: no raw HA entity/service/payload history, no light-only
path, no per-cycle identical-value writes, no learning from unproven resident
origin, no new direct action authority, and no history used as a live hold.

## Scenario matrix to verify

| Scenario | Required historical interpretation |
|---|---|
| Verified resident dims a light or sets a valve position | Resident edge id joins one changed canonical channel-state fact; the descriptor's versioned reverse projection yields one valid member target only after a forward round trip. |
| Wall switch removes bulb power | Bulb becomes unavailable; no bulb resident event, correction or routine member. Any count/assembly window crossing it is censored. A separately registered verified switch may have its own event. |
| Heima decision is already satisfied | One admitted decision and one full-target observation anchor; no ApplyCall, one denominator episode. |
| Dispatched calls fail, but a later valid state matches the full target | Observation anchor may occur later without revising the terminal execution outcome. |
| Only some facets match or matches never coexist | No full-target anchor and no zero-count sample. |
| Target is observed, then no resident correction occurs during a complete window | Exactly one zero sample, subject to current-policy episode and coverage. |
| One or multiple verified resident corrections | Deduplicated correction events join one anchor and produce count 1 or 2+. |
| Resident restores a targeted facet to the expected value, then changes it away again | The restoring edge is not a correction; the second departing edge can count under the same still-current anchor if the complete target matched immediately before it. |
| Another admitted target or authority change supersedes the anchor | Earlier window is censored, never shortened into a zero. |
| External/unknown edge changes a candidate channel | Routine window is confounded; optional diagnostic attribution is not resident learning evidence. |
| Crash, unavailable channel, missing history or failed durable write | Coverage/retention makes the affected window incomplete; no fabricated negative or zero. |

These are specification counterexamples. No executable V3 runtime test has run.

## Semantic review result

The owner text was checked against the matrix. Two channels at one Location
receive distinct SHA-256-derived fact types, preserving Layer 0's WHAT+WHERE
identity. A channel-state value uses only scalar canonical facet text, a
flat changed-facet list and bounded identifiers, so its worst case can be
proved against Layer 1's depth-two/8 KiB limit before staging. The paired
resident event keeps exactly its previously approved three-field value.
Equal-time decision/complete-observation facts are joined by explicit
`apply_step_id` and phase, never by `AppendOrder` causality. Target lifecycle
facts append only on admitted transitions and use stable per-phase ids;
unconfirmed commands supply no denominator until a real complete match.
The ordinary channel-state unavailable transition and process coverage
censor windows. No new live hold, resident-facing switch, HA call path or
device-specific learner is introduced. External/unknown diagnostics consume
normalized edges, while only a verified resident event can produce the
resident-learning classification. The exact historical retention demand is
declared by each registered learner, using Layer 0's existing per-stream
coverage and pruning rules.

This is document-level scenario evidence, not a runtime result. The
structural checker and `git diff --check` are run separately at closure.
