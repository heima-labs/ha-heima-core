# CA4-38 — bounded durable retry queue and declared loss

**Status:** specification reviewed (2026-10-10).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Approved decisions and exact gap

The developer approved a bounded queue with declared loss (option A), a budget of
`max(32 MiB, 5% of the effective memory limit)` with 32 MiB when no limit is known, revisable from
evidence, and the dedicated gap reason `queue_overflow`. Blocking admission and an unbounded queue
were rejected. Layer 0 previously retained every failed batch item for retry with no memory bound
and no rule for reporting what could not be kept.

## Reuse and owners

Layer 0 §4.6 owns the budget and the overflow order (collapse superseded state transitions, then
drop oldest events), reusing write-on-change state semantics, per-stream identity, the stream-gap
metadata path and the continuity watermark of §4.4. The budget reads the existing
`RuntimeHealthSnapshot` memory limit outside the evaluation path. Layer 3 §4.4.2 treats the new
reason as an observation gap. Diagnostics, failure handling, overview and recap are aligned. The
follow-up outbox is a separate durable store and is unaffected.

## Scenario review

| Scenario | Required result |
|---|---|
| Long storage outage with a flapping sensor | Latest state retained; intermediate transitions lost with one merged `queue_overflow` interval. |
| Event volume still exceeds budget | Oldest events dropped with per-stream intervals; admission and HA commands never block. |
| Storage recovers | Gap boundaries commit with or before retained items; watermark advances only past declared losses. |
| Crash before recovery | Unadvanced watermark already marks the interval incomplete. |
| Correction-count or routine window over a lost interval | Excluded as an observation gap, never zero or negative. |
| Unaffected stream | Remains complete. |
| Health snapshot lowers the budget | Applies at the next overflow check; nothing discarded retroactively. |
| Dropped hold-audit fact | Live hold unaffected; audit stream reports the lost interval. |

This is document-level evidence; no V3 runtime test has run.
