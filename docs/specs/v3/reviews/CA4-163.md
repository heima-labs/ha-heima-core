# CA4-163 — referenced components in composed names

**Status:** specification reviewed (2026-10-28).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 2 §2.7 presentation names: composed names compared in every shipped
  locale, live HA names not checked, Opening uniqueness within its owning room, global Reaction
  uniqueness; names excluded from semantic fingerprints.
- **Gap.** Room component of a composed name undefined as id or name.
- **Overlap check.** No new construct; one rule for referenced components.
- **Owners.** Layer 2 §2.7, §9.
- **Responsiveness.** Staging and rendering only.

## Decision (developer-approved 2026-10-28)

Compare referenced components by stable id; render them by effective name.
