# CA4-45 — frozen recovery inputs in DecisionSnapshot

**Status:** specification reviewed on 2026-10-05.
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

Layer 0 §7.4 computes one current recovery state and exposes copied per-channel,
per-facet baselines; CA4-03 fixes their identity and authority anchors. Layer 4
§5.1 currently transports history, calendar, hold and ownership views but omits
recovery inputs. Layer 5 therefore cannot reconcile a baseline using only its
immutable `DecisionSnapshot`.

Reuse the existing `CycleInputBarrier`, copied Layer-1 projections, Layer-5
generation authority projection and `snapshot_id` fingerprint. Layer 0 owns the
recovery state and baselines; Layer 5 owns the current Reaction-authority view;
the coordinator freezes them at one barrier and Layer 4 transports them opaquely.
This preserves V3's one action path, immutable-cycle evaluation and clean-start
recovery. Review a stable retry, new baseline commit, consent revocation, a
power-recovery state change, an unreadable channel and a post-barrier update.

| ID | Scenario | Required result |
|---|---|---|
| S1 | Retry of one completed intake barrier | Same recovery/authority views and `snapshot_id` |
| S2 | New checkpointed baseline or recovery classification in the next cycle | New view fingerprint and snapshot identity |
| S3 | Consent revoked before barrier | Authority view is non-automatic; its baseline facet is filtered |
| S4 | Consent revoked after barrier but before command | Frozen decision unchanged; dispatch fence blocks the command |
| S5 | One channel unreadable while another is readable | No inferred match on unreadable channel; readable channel can reconcile under current policy |
| S6 | Checkpoint commit after barrier | Current snapshot retains old frozen baseline; next snapshot may use new one |
| S7 | Ordinary restart, no confirmed power recovery | No recovery baseline action; no stale confirmation request restored |

**Review result:** Layer 0 §7.4, Layer 5 §4.2/§8, Layer 4 §5.1/acceptance,
overview and recap agree on snapshot ownership and identity. CA4-27 still owns
cross-layer generation commit. No executable V3 runtime test has run.
