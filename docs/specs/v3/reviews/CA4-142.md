# CA4-142 — Layer-5 descriptor rules

**Status:** specification reviewed (2026-10-21).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** Layer 5 §3.2 guard contracts and `safe_direction_intents` /
  `low_risk_intents`; `safety.weather_protection.guards.v1` as an explicit empty contract;
  CA4-122 pause, minimum absence and recovery horizon ("abstains"); CT-2 comfort prerequisite
  (2026-09-23); §4.1 proposal acceptance creating a new root; command 4 promotion and command 6
  disablement; §5.2 closed outcome validation; §6.0 whole-cycle arbitration; §7.4 start criterion
  and restart rule; Layer 8 §6.1 confirmation dialog.
- **Gap.** Audit group G6: F-L5a-01, F-L5a-02, F-L5a-04, F-L5b-01, F-L5b-02.
- **Overlap check.** Two contracts are registered in the existing contract form. The outcome rule
  reuses existing outcomes and `outside_operating_envelope`. The learner-origin path reuses proposal
  acceptance. The overlap notice is advisory text in the existing confirmation dialog, with no new
  command, result code or block. Verified that no existing staging check forbids two automatic
  Reactions on one channel; runtime arbitration blocks both, and cross-descriptor sharing is
  intended (weather protection with shading, several hazards on one window).
- **Owners.** Layer 5 §3.2, §4.1, §4.2, §5.2, §7.1, §7.3, §7.4, §7.5, §8; Layer 8 §6.1.
- **Responsiveness.** One extra guard evaluation per comfort-trajectory evaluation, like every other
  descriptor; the overlap notice is computed at governance time from the staged channel index.

| Restart during an active wind hazard | Start criterion true; new activation secures the window. |

| Shading and weather protection on one cover | No notice; guards prevent opposition. |
