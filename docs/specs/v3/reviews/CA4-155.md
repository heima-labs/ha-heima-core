# CA4-155 — structured household fact contracts

**Status:** specification reviewed (2026-10-25).
**Evidence type:** `textual_contract_and_scenario_review`.
**Runtime test:** `not_run_v3_not_implemented`.

## Impact record

- **Existing decisions.** CA4-121 one atomic fact per declared context with object values; CA4-153
  `FactValueContract`; Layer 7 exclusion of `household.*` from slots; consumers Layer 5
  `planned_absence_program`, Layer 3 household-context censoring, Layer 8 entities.
- **Gap.** No contract kind for an object value.
- **Overlap check.** Reuses `FactValueContract` with one kind and one field; schemas are owned by
  the producing layer (Layer 2 §2.9), not a new registry layer.
- **Owners.** Layer 1 §3; Layer 2 §2.3, §2.9, §9; Layer 3 §4.2; Layer 5 §5.1; Layer 8 §10.1.
- **Responsiveness.** Staging only.

## Decision (developer-approved 2026-10-25)

`structured` kind with exact-schema equality; consumers bind by schema id.
